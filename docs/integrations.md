# Integrations

The support and CRM connectors are deterministic local demo implementations. Gemini is not called by this build; configuring `GEMINI_API_KEY` only marks the connector as configured and does not imply a successful live test. SMTP, arbitrary REST, and n8n are not wired into the execution engine. The knowledge index supports TXT and Markdown with lexical overlap scoring. PDF, DOCX, sentence-transformer embeddings and FAISS are not currently implemented.
